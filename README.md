# GOLD MATRIX BOT v0.1

MVP rule-based gold signal engine. Paper mode only.

Pipeline:
Data -> Structure -> Liquidity -> Setup -> Confluence -> Risk -> Signal

Current implementation:
- Swing high/low detection
- BOS / CHOCH
- Liquidity sweep
- FVG detection
- Basic confluence score
- Exact entry/SL/TP proposal
- Backtest-ready signal function
- Telegram sender (optional)
- GitHub Actions skeleton

No live trading is implemented.
